# REQUIREMENTS.md — TODO 管理アプリ（loop-eval fixture）

> このファイルは確定済み（TP1 承認済み扱い）。dev-flow の /loop-eval が使う評価用 fixture。

## 目的

チーム内の小さなタスクをブラウザで管理する最小 TODO アプリ。

## ユーザーストーリー

- US1: ユーザーとして、TODO の一覧を見たい（実装済み）
- US2: ユーザーとして、TODO を追加したい（実装済み）
- US3: ユーザーとして、TODO を完了にしたい（実装済み・API のみ）
- US4: ユーザーとして、名前を指定して挨拶メッセージを取得したい（**未実装**）
- US5: ユーザーとして、TODO の統計（総数・完了数）を画面で確認したい（**未実装**）

## 非機能要件

- 認証なし（社内ツール想定）
- データはインメモリでよい（永続化不要）
- 日本語 UI
