## 1. 入力バリデーション・XSS

### 1.1 反射型 XSS
テキスト入力欄・検索欄・URLパラメータに以下を投入し、エスケープされて表示されることを確認する:
- `<script>alert('XSS')</script>`
- `<img src=x onerror=alert('XSS')>`
- `javascript:alert('XSS')`（リンクURL欄用）
- `"><svg/onload=alert('XSS')>`

### 1.2 格納型 XSS
DB 保存後に再表示する画面（詳細画面・一覧）でペイロードが実行されないことを確認する。

### 1.3 HTML サニタイズ
リッチテキスト入力がある場合、許可タグ以外が除去されることを確認する。

### 1.4 検証手段
`mcp__chrome-devtools__list_console_messages` で `alert()` 等の実行ログが出ていないことを確認する（出たら Critical）。

## 2. SQL インジェクション

### 2.1 ペイロード
検索欄・ID パラメータ・ログインフォームに以下を投入:
- `' OR '1'='1`
- `'; DROP TABLE users; --`
- `1 UNION SELECT * FROM users`
- `admin'--`

### 2.2 期待動作
- **400/422 エラーで拒否** または **文字列として安全に扱われる**
- 500 エラー / DB 構造露出 / 認証バイパスが起きたら Critical

### 2.3 留意点
ORM を使用していても **raw SQL / `text()` / `LIKE` 結合箇所**は個別に確認する。

## 3. 認可（権限チェック）

### 3.1 水平権限越境（IDOR）
- ユーザーA でログイン → ユーザーB のリソース ID（`/api/users/<Bのid>`, `/api/reports/<Bのid>` 等）にアクセス
- 期待: **403 または 404**。データが返ってきたら Critical

### 3.2 垂直権限越境
- 一般ユーザーで管理者専用エンドポイント（`/admin/*`, 削除系 API 等）にアクセス
- 期待: **403**

### 3.3 未認証アクセス
- トークン無し / 期限切れトークンで保護エンドポイントにアクセス
- 期待: **401**

### 3.4 フロント隠蔽頼みでないこと
メニュー非表示だけでなく、**API 側でも拒否される**ことを確認する。

## 4. CSRF・セッション

### 4.1 Cookie 認証
- Cookie 認証を使っている場合、`SameSite` 属性（`Lax` / `Strict`）が設定されていることを確認
- CSRF トークン検証の有無を確認

### 4.2 セッション失効
- ログアウト後に旧セッショントークンが無効化されていることを確認
- パスワード変更後に他セッションが失効すること（該当機能がある場合）

## 5. 機密情報・シークレット

### 5.1 ハードコード
```bash
git grep -iE "(password|secret|api[_-]?key|token)\s*=" -- '*.ts' '*.py' '*.env*'
```
ヒットがあれば Critical（コミット履歴に残っている場合も含む）。

### 5.2 レスポンス漏洩
- パスワードハッシュ・内部トークン・スタックトレースが含まれていないこと
- API レスポンス JSON を全フィールド確認

### 5.3 エラーメッセージ漏洩
- DB 名・テーブル名・ファイルパス・スタックトレースがエラー画面に出ていないこと

### 5.4 .gitignore
- `.env`, `credentials.json` 等が `.gitignore` されていること
- `git ls-files | grep -E "\.env$"` で誤コミットを確認

## 6. ファイルアップロード

**該当機能がない場合はスキップ理由を記録してスキップ可。**

- 拡張子偽装（`.jpg.exe`, `.php`, `.svg` 内の `<script>`）が拒否されること
- ファイルサイズ上限が設定されていること
- アップロード先パスが予測困難・直接アクセス不可であること

## 7. セキュリティヘッダ

`mcp__chrome-devtools__list_network_requests` でレスポンスヘッダを確認し、以下の存在を確認する（Web アプリの場合）:
- `Content-Security-Policy`
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options` または CSP の `frame-ancestors`
- `Strict-Transport-Security`（HTTPS 環境）

## 8. 依存ライブラリ脆弱性

```bash
npm audit --audit-level=high   # フロントエンド
pip-audit                      # Python（pip-audit 導入時）
```

**High 以上の脆弱性が残っている場合は修正必須**（修正自体は呼び出し側で別エージェントが担当）。
