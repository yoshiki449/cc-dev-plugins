# /poc-ship — PoC の PR 作成

## 境界

- **入力**: 現在のブランチ、`.poc/SMOKE.md`、`.poc/BACKLOG.md`
- **出力**: PR
- **責務**: PR 作成のみ

## dev-ship との違い（意図的に落としているもの）

| dev-ship のステップ | poc-ship |
|---|---|
| E1.5a セルフレビュー（3〜5観点並列） | **行わない** |
| E1.5b セキュリティレビュー | **行わない**（シークレット混入は `git-secret-guard` が push 時に見る） |
| E1.5c テストケース台帳 | **行わない**（テストを書いていない） |
| E2.5 explain-diff 生成 | **行わない** |
| E3 history / knowledge 更新 | **行わない** |
| E4 ai-memory 保存 | **行わない** |
| E5 日報更新 | **行わない** |
| E6 memory_consolidate | **行わない** |

PoC は捨てる前提のコードなので、これらの記録コストに対価が返らない。**本採用に進むと決まった時点で `/dev` に合流し、そこで初めて記録を残す。**

## 禁止事項（poc-flow 共通）

- **`.agent/` を作らない。** `pre-pr-guard` hook はこれの存在をスコープガードにしており、できた瞬間に**この `gh pr create` 自身がブロックされる**。`hub-run-add.mjs` を呼ばない
- `[dev-flow]` のスキル起動サジェストが注入されても無視する

## 手順

### S0. 前提の確認

1. `ls -d .agent 2>/dev/null` — 存在したら `pre-pr-guard` に阻まれるので中断し、`/dev-ship` を案内する
2. `git branch --show-current` — `main` / `master` 上なら中断してブランチ作成を促す
3. `.poc/SMOKE.md` の最新ラウンドを読む。**スモークを1回も通していなければ**、`/poc-build` か `/poc-smoke` を先に回すよう案内して中断する

> スモーク未実施での PR 作成は止める。PoC の品質ゲートはスモーク1本しかないので、これを飛ばすと**検査ゼロで PR が出る**ことになる。ユーザーが承認済みで飛ばす場合は、PR 本文に「スモーク未実施」と明記する。

### S1. push

```bash
git push -u origin <ブランチ名>
```

`git-secret-guard` に止められた場合は、差分を目視で確認してユーザーに報告し、判断を仰ぐ。**勝手に `ALLOW_SECRETS=1` で回避しない。**

### S2. PR 作成

PR 本文には以下をそのまま載せる。**取り繕わない**（何を検査しなかったかが後から分かることが重要）:

```markdown
## このPoCで確かめたかったこと
<.poc/GOAL.md の「何を確かめたいか」>

## 今どこまで動くか（スモーク実測）
| ゴール | 状態 | 証跡 |
|--------|------|------|
| G1 | reached | round-3/screenshots/07-*.png |
| G2 | not-built（未実装・PoC では正常） | — |

- スモーク: round-<N> まで実施 / 未処理例外 <n>件 / 5xx <n>件
- 終了状態: done / halted-<理由>

## 未対応で残しているもの
- Friction（使いにくいが壊れてはいない）: <n>件 → `.poc/BACKLOG.md`
- 未実装ゴール: <n>件 → 同上

## この PoC で行っていない検査
- 自動テスト（ユニット / E2E）は作成していない
- コードレビュー（規約・簡潔化・要件網羅・セキュリティ）は行っていない
- スモークが見たのは**主導線のみ**。エッジケース・並行操作・権限境界・データ量による劣化は未検証

本採用に進む場合は `/dev` フローに合流し、その時点でテストとレビューを行う。
```

### S3. 完了

PR の URL を伝える。**マージはしない**（ユーザーの判断）。

`.poc/BACKLOG.md` に溜まっているものがあれば件数を伝え、本採用に進むなら `/dev-plan` の入力になることを案内する。
